# Contribuindo

## Convenções iniciais

- Toda entrega deve referenciar a issue Jira correspondente no commit, PR ou evidência.
- Mudanças de arquitetura entram em `docs/adr/`.
- Pipelines precisam ter fixture, caminho de rerun e criterio de recuperacao descrito.
- Segredos ficam fora do repositorio. Use `.env.example` para documentar variaveis.

## Definition of Done

- Critérios de aceite demonstrados.
- Testes proporcionais ao risco.
- CI aprovado quando existir.
- Documentação, runbook ou ADR atualizados quando aplicável.
- Evidência ligada ao commit.
